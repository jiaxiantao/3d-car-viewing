此目录不是在线演示站点

docs/ 仅存放项目文档（架构说明、技术博客等）。Next.js 3D 看车应用体积较大，由 CI 构建后发布到 gh-pages 分支，而不是直接放在本目录。

若访问 在线预览 出现空白或 404，请在仓库中完成一次 Pages 配置：

  1. 打开 Settings → Pages → Build and deployment
  2. Source 选择 Deploy from a branch
  3. Branch 选 gh-pages，文件夹选 / (root)（不要选 main /docs）
  4. 保存后等待 Deploy GitHub Pages 工作流完成

详细说明见仓库 docs/GITHUB_PAGES_SETUP.md。
